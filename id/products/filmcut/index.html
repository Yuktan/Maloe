Filmcut

Aplikasi Mac · arsip film

Satu frame, satu foto yang rapi.

Filmcut membaca folder hasil scan, mengenali setiap rol, melewati file duplikat, membagi tiap gambar dua frame di tengah, lalu memberi nomor dari 000001 untuk setiap rol. Semuanya berjalan offline dan file asli tetap ada.
